## Getting Started

You can run these C++ programs either by downloading the pre-compiled executables or by building them directly from the source code.

### Option 1: Quick Start (Pre-compiled Binaries)
If you just want to run the programs instantly without compiling them:
1. Go to the **[Releases](../../releases)** section on the right side of this GitHub page.
2. Download the executable files (`program1`, `program2`, etc.) from the latest release assets.
3. Open your terminal, navigate to your downloads folder, and give the file execution permissions:
   ```bash
   chmod +x program1
   ```
4. Run the program:
   ```bash
   ./program1
   ```

### Option 2: Build from Source (Compilation)
If you want to view, modify, or compile the source code yourself on your machine:

#### Prerequisites
Ensure you have a C++ compiler installed (like `g++` or `clang`). On Arch Linux, you can install the complete development tools via:
```bash
sudo pacman -S base-devel
```

#### Steps to Run
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com
   cd your-repo-name/day1
   ```
2. Compile the desired `.cpp` file using `g++`:
   ```bash
   g++ program1.cpp -o program1
   ```
3. Run your freshly compiled binary:
   ```bash
   ./program1
   ```
